# Neural Network Fundamentals

This module introduces the mathematical and computational foundations of neural networks using Python and PyTorch.

The focus is on understanding how neural networks process inputs, calculate predictions, measure errors and learn through optimisation.

## Topics Covered

|Topic	| Key Concepts | Status |
| --- | --- | --- |
| Tensor Fundamentals	| Scalars, vectors, matrices, tensor shapes and dimensions | ✅ |
| Matrix Multiplication |	Matrix operations, dimensions and broadcasting | ✅ |
| Activation Functions | ReLU, Sigmoid, Tanh and non-linearity |	✅ |
| Forward Propagation | Linear transformations, weights, biases and MLP architecture |	✅ |
| Loss Functions | Mean Squared Error and prediction error |	✅ |
| Gradient Descent | Gradients, learning rates and parameter updates | ✅
| Backpropagation | Chain rule and automatic differentiation |	✅ |
| Optimisation | SGD, convergence and learning-rate experiments |🟡 |
| Neural Network Classification | Building and training an MLP classifier |	⬜ |

## Practical Work

## Technologies & Tools

* Python: Primary programming language.
* PyTorch: Tensor operations, neural network implementation and automatic differentiation.
* NumPy: Numerical computing.
* Matplotlib: Visualisation of training behaviour and experimental results.
* Jupyter Notebook: Interactive experimentation and documentation.
* uv: Python project and dependency management.

## Key Learning Outcomes

By completing this module, I aim to be able to:

* Understand tensor operations and matrix multiplication.
* Explain how weights, biases and activation functions work.
* Implement basic neural networks using PyTorch.
* Explain forward propagation and backpropagation.
* Understand how gradients influence parameter updates.
* Compare optimisation algorithms and learning rates.
* Train, evaluate and interpret a basic neural network.
