# Mastering GenAI & Agentic AI Engineering

A hands-on learning journey covering the foundations of Machine Learning, Deep Learning, Generative AI and Agentic AI Engineering.

The goal is to build a strong understanding of the underlying concepts through a combination of theory. practical implementations, experiments, and projects.

## Learning Roadmap

| Module | Topics | Projects/Practical Work | Status |
| --- | --- | --- | --- |
| 01. Neural Network Fundamentals | Tensors ✅, matrix multiplication ✅, activation functions ✅, forward propagation ✅, loss functions ✅, gradient descent ✅, backpropagation ✅, and optimisation ✅ | PyTorch Linear Regression ✅; Learning Rate Comparison ✅; MLP Classification | 🟡 In Progress |
| 02. Attention & Transformers | Self-attention, Query-Key-Vlue, scaled dot-product attention, multi-head attention, positional information & casual masking | Implement Scaled Dot-Product Attention from Scratch | ◻️ Planned |
| 03. LLM Fundamentals & Hugging Face | Tokenisation, embeddings, context windows, logits, decoding strategies, model weights & inference | Text Generation Playground | ◻️ Planned |
| 04. Agentic AI Foundations | AI agents, tool calling, agent architectures, memory, planning & orchestration| TBA | ◻️ Planned |
